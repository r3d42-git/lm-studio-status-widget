# LM Studio Status Widget 1.2.1

- Local releases now select the G2 Developer ID Application certificate by its SHA-1 fingerprint `D548540E7FE1BD9B3C4518CC02D8786E1BFEB885`. A missing or invalid identity stops the release before tests and signing; `MACOS_SIGNING_IDENTITY` remains an override.
- Starting with this release, the app is licensed under GPL-3.0-or-later. The packaged app contains the complete GPLv3 text and licensing notice. `LICENSE-MIT` preserves the earlier MIT license and copyright notice; earlier releases retain their MIT license.
- Local release and downloaded-artifact checks compare the packaged license files with the source.

App behavior is unchanged from v1.2.0.
